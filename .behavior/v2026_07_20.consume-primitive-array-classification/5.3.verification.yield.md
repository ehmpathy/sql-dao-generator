## the one residual — downstream-owned

the emitted `prop.ARRAY_OF(prop.<primitive>())` is inert until `sql-schema-generator` ships native
arrays; its `ARRAY_OF` accepts only `REFERENCES` / `UUID` today. this repo's contract — the emission —
is proven above. a live round-trip test here would run red against the dependency that throws, so it
cannot be written without a failhide. handed off: `handoff.sql-schema-generator.md`.

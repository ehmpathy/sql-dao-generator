## .the fork

one definer inlined four generated files: `AsJsonFromDbObject`, `DbValueCastError`,
`asDateFromDbValue`, `asNumberFromDbValue`.

| side | argument |
| --- | --- |
| split | every other definer defines one artifact; `rule.require.sync-filename-opname`. and the bundle hid a real edge: the parser-supply definer consumed two artifacts this definer wrote, enforced only by a test that walked generated import strings |
| keep | the four are a transitive closure — ship any three and the code does not compile |

⇒ the closure justifies **co-emission**, never one function. the drive conceded the merits at i021
and deferred on when, not whether.

## .the ground that was wrong

the `dirty` grade rested on round cost: a 438-line re-home would void every reviewer cache and mint a
new round with 2 of 18 left on each l3 lane.

- the count was right. the engine prints `16 rounds, 18 budget — 2 rounds left`. a glob of
  `.reviews/**` read 5 givens and briefly "falsified" it — a proxy read where the source that owns
  the number prints it one command away
- the ground was wrong regardless. **a round budget is a cost of the change; `dirty` is a property of
  the rework** — callers hardened, or later work built upon it. a re-review round is neither
- the transcription risk was already clamped: the import-walk test goes red on a dropped file, the
  snapshots on a changed byte

⇒ SAFE and CLEAN, so `rule.always.defer-fulcrums-to-last` licensed no defer.

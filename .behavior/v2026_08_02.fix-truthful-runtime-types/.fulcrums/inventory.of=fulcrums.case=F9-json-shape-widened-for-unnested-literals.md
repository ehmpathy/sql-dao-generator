## .what was taken

`Certificate`, `Geocode`) is nested, so the narrow moves zero generated bytes here.

CLEAN 🔴: `getAllNestedDomainObjectNames` answers the outbound question (*what does this nest?*); the
narrow needs the inbound one (*who nests this?*), which only `allSqlSchemaRelationships` answers.

- the cost is one signature and one argument. `defineDaoCodeFilesForDomainObject` already holds

- 18 call sites would gain a field: 1 production, 1 peer suite, 16 in the cast definer's own test
- 🟡 this entry first said *two* signatures. i022 r011 caught it. the count was the half that made
  the defer read as obvious — the F8 lesson again: a structural claim inside a defer is checkable

⇒ CLEAN stays 🔴 as a chore, and cost is not the question the council owes.

consumer's dao directory, which the vision ruled a break. so the narrow may become permanently
unavailable once a consumer releases against it — the defer may be more right than it looks.

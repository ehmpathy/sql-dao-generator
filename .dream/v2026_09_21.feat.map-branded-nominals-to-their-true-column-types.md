# 🌙 dream: map branded nominals to their true column types

- kind  = feat
- owner = `ehmpathy/sql-dao-generator`
- caught = 2026-09-21
- status = open

## .the cue that fired
the wisher asked: *"for dates — what if we just required it to translate into IsoTimeStamp notation,
and if we see it's an iso time stamp we parse it?"* the block to that is this repo.

## .the gap, precisely
- `domain-objects-metadata` already extracts a brand: `{ type: 'NOMINAL', of: { name, primitive } }`,
  with a registry of 18 brands (`IsoTimeStamp`, `IsoPriceWords`, `Uuid`, `Hash`, …)
- this repo holds zero references to `NOMINAL` (`rhx grepsafe --pattern NOMINAL --path src`)
- ⇒ a branded property falls past every branch of `defineSqlSchemaGeneratorCodeForProperty.ts` and
  hits its terminal `UnexpectedCodePathError('unsupported domain object property type')`

a loud throw, not a silent wrong column — so a capability never built, not a defect in haste.

## .what it buys
1. **the date cast turns from a convert into a format check.** `rule.forbid.any-time` forbids `Date`
   as a declared shape, so every consumer this generator serves is non-conformant and cannot become
   conformant. with `IsoTimeStamp` honored, the json path already holds the declared type; the raw
   path owes a `Date` → iso render
2. **money keeps its currency.** `IsoPriceWords` is `'USD 50.37'`; a `NUMERIC` column drops the
   currency. the honest map is `VARCHAR`. this closes the money gap the vision flagged as out of scope
3. **`Uuid` becomes a type fact.** today `prop.UUID()` is chosen by a `_uuid$` name regex, so the
   name decides rather than the type. a bonus, never the justification

## .the shape of the fix
```ts
// defineSqlSchemaGeneratorCodeForProperty.ts
const definePropExpressionForNominal = (nominal: DomainObjectNominalMetadata): string | null => {
  if (nominal.name === 'IsoTimeStamp')  return 'prop.TIMESTAMPTZ()';
  if (nominal.name === 'IsoDateStamp')  return 'prop.DATE()';
  if (nominal.name === 'Uuid')          return 'prop.UUID()';
  if (nominal.name === 'IsoPriceWords') return 'prop.VARCHAR()'; // the currency rides in the value
  return null; // fall back to the base primitive, never a throw
};
```

plus the sites that read property type: the reserved `created_at` check in
`defineSqlSchemaRelationshipForDomainObject.ts`, the cast in
`defineDaoUtilCastMethodCodeForDomainObject.ts`, and `getOneCastNameForProperty.ts`.

⇒ an unregistered brand falls back to its `primitive`, so the map is open, not an allowlist.

## .why it is not done in this round
not SAFE — it changes generated DDL; `IsoTimeStamp` → `TIMESTAMPTZ` is a column type change for an
extant consumer. not CLEAN — each brand's column is a design call (`IsoPriceWords` → `VARCHAR` gives
up sql sort and sum). and it answers a different question from the wish: which column a brand gets,
upstream of the cast.

⇒ it shrinks `v2026_09_21.feat.cast-json-nested-values-to-text-in-the-generated-sql.md`: with
`IsoTimeStamp`, the json date needs no `::text`. read both.

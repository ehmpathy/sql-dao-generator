# 🌙 dream: scope depcheck off the vendored `.agent/` role skills

- kind  = fix
- owner = `ehmpathy/sql-dao-generator`
- caught = 2026-09-09
- status = ✅ discharged within the same route

## .how it was discharged
`.depcheckrc.yml` now carries `ignore-patterns: [.agent]`, scoped by path rather than package
name, so the next role bump with a new import stays green.

the blanket form also skips `.agent/repo=.this/`, which this repo authors. that dir holds briefs
today, no `.ts` with imports, so no check was given up in practice.

## .the cue that fired
`rhx git.repo.test --what lint` went red on a diff that touched no dependency — depcheck alone
reported `declastruct-aws`, `declastruct-unix-network`, and `playwright` absent, from files under
`.agent/repo=ghlitch/…` and `.agent/repo=bhrowser/…`.

## .the gap, as it stood
- those files belong to installed role packages, not this repo's source
- `.agent/repo=*/…/skills` are symlinks into `node_modules`, created by `prepare:rhachet`
- the CI `test-lint` job never runs `prepare:rhachet` (`.github/workflows/.test.yml`), so CI was
  green and every local tree with roles booted was red

🟡 `.agent` is **not** gitignored (`git check-ignore .agent` exits 1). the discriminator is that
the lint job skips `prepare:rhachet`.

# 🌙 dream: a structural guard for the two defect classes that recurred ~5× each

- kind  = fix
- owner = `ehmpathy/sql-dao-generator`
- caught = 2026-09-13
- status = 🟡 half — class 1 is closed locally, open in CI; class 2 is open

## .the cue that fired
a peer review named a pattern, not an instance: two defect classes recurred about five times each,
and a human caught every one — no hook, no CI step. the round it wrote in held a sixth: a vision
claim about `COALESCE` → `[]` that nobody had run.

## .the gap, precisely

| class | what it looks like | state |
| --- | --- | --- |
| **stale generated artifact** | a fixture or snapshot holds an older definer's output | 🟡 `test:unit` and `test:integration` regenerate the example project first, so no suite grades a stale fixture. the **committed** fixture can still drift, and CI does not diff it |
| **prose over-claim** | a comment or claim asserts behavior nobody executed | open — no check |

## .the shape of the fix
**class 1 — a CI diff check.** the generator is deterministic, so a clean tree after a regenerate
is the invariant:

```sh
npx tsx ./bin/run generate --config .../codegen.sql.dao.yml
git diff --exit-code src/domain.operations/.test.assets/exampleProject
```

it must run after `sql-code-generator`, which writes second, or it false-positives on files that
pass rewrites.

**class 2 — no full mechanism.** a claim about generated output is checkable by a run, and a run
costs less than the round spent to argue it. that is a rule rather than a hook — a seed for
`bhrain/role=learner`.

## .why it is not done in this round
SAFE — a CI step adds no runtime behavior. not CLEAN — `.github/workflows/` is a file this route
never opened.
